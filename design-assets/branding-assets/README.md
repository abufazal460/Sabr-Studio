# Sabr Studio website branding assets

All marks are derived from the supplied raster source without redrawing, reshaping, or changing lettering. Transparent PNGs have a real alpha channel; white and black marks are contrast variants for dark/light placements.

The supplied files contained no separately named PWD mark. `pwd/` therefore contains the existing architectural emblem only, kept independent from the Sabr Studio wordmark.

The SVG files are deliberately raster-backed SVG wrappers around the cleaned PNG artwork. This preserves the supplied design more faithfully than an automatic vector trace; they are not claimed to be native vector reconstructions.

`masters/4096px` are high-resolution exports from the supplied raster artwork. They are suitable for placement where raster scaling is needed, but are not claimed to be native 4K source artwork.
